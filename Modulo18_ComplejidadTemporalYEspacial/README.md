## Main Topics

The module focuses on two fundamental measurements:

### Time Complexity

Describes how the amount of work performed by an algorithm grows relative to the size of its input.

Examples of commonly analyzed complexity classes include:

- `O(1)` — constant time
- `O(log n)` — logarithmic time
- `O(n)` — linear time
- `O(n log n)` — linearithmic time
- `O(n²)` — quadratic time

### Space Complexity

Describes how much additional memory an algorithm requires as its input size grows.

This includes reasoning about:

- Constant extra memory
- Auxiliary containers
- Temporary variables
- Data structures whose size depends on the input

## Why This Module Matters

Two algorithms can produce the same result while having very different performance characteristics.

Big O analysis provides a way to compare approaches based on how well they scale rather than only whether they produce the correct answer.

This becomes especially important when working with:

- Searching algorithms
- Sorting algorithms
- Hash tables
- Two Pointers
- Sliding Window
- Prefix Sum
- Recursive algorithms
- LeetCode-style problems
