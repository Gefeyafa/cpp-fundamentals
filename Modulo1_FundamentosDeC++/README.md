# Module 1 — C++ Fundamentals

This module introduces the basic structure of a C++ program, console input and output, variables, arithmetic expressions, and simple value manipulation.

The exercises progress from printing a basic message to receiving user input and performing simple calculations.

## Exercises

### Exercise 1 — Hello World

A basic program that prints `Hello World` to the console.

**Concepts practiced:**
- Basic structure of a C++ program
- `#include <iostream>`
- The `main()` function
- Console output with `cout`
- Line breaks with `endl`

---

### Exercise 2 — Console Output

Prints several lines of text to the console using multiple `cout` statements.

**Concepts practiced:**
- Console output with `cout`
- String literals
- Multiple output statements
- Sequential execution of instructions

---

### Exercise 3 — Console Input

Asks the user for their name and age, stores the values, and displays a personalized message.

**Concepts practiced:**
- Declaring variables
- `string` and `int` data types
- Reading input with `cin`
- Displaying variables with `cout`
- Combining text and variables in console output
- Using the `<string>` library

---

### Exercise 4 — Basic Calculator

Receives two integer values and calculates their sum, subtraction, multiplication, and division.

**Concepts practiced:**
- Integer variables
- User input
- Arithmetic operators:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
- Storing calculated results in variables
- Displaying calculation results

> Since the exercise uses `int`, division is performed using integer division.

---

### Exercise 5 — Swapping Values

Receives two numbers and swaps their values using a temporary variable.

**Concepts practiced:**
- Variable assignment
- Preserving a value with a temporary variable
- Changing program state
- Understanding the order of assignments
- Swapping two values

The basic swap process used in the exercise is:

```cpp
temporal = a;
a = b;
b = temporal;
```

---

### Exercise 6 — Age Converter

Receives the user's age in years and calculates approximately how many months and days they have lived.

**Concepts practiced:**
- Arithmetic expressions
- Multiplication
- Using variables inside calculations
- Performing calculations directly inside `cout`
- Simple unit conversion

The exercise uses the approximations:

- 12 months per year
- 365 days per year

- Console input and output
- Variables and basic data types

- Sequential program execution
- Simple calculations
- Basic value manipulation
